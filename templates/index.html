The numbers come from F1Laps. For each setting, the sheets use the value most of the 20 fastest setups F1Laps lists for the track run. F1Laps' own meta setup takes the median of its 100 fastest setups, so some values differ from it. Most of those laps are Time Trial laps, which have no tyre wear.

The game can't import setup files. Type a setup in once, then save it in the game as a custom setup for that track.
